# 页面资源边界

> 状态：当前资源目录说明
>
> 更新时间：2026-08-15
>
> 适用范围：`apps/web/public/resource/` 中的视频与图片
>
> 替代关系：替代旧的示例内容和部署教程；项目事实与发布边界以根文档为准

本目录只保存页面静态资源，不证明图片中的作品、学生、奖项、合作方或产品效果真实存在。使用前读取 [`../../../../AGENTS.md`](../../../../AGENTS.md) 和 [`../../../../CURRENT_STATUS.md`](../../../../CURRENT_STATUS.md)。

新增或替换资源时必须记录：

- 来源、授权范围、版权状态和负责人；
- 涉及学生或未成年人时的监护同意、隐私处理和公开范围；
- 文件用途、目标页面、版本和替换关系；
- 与页面文字对应的事实证据。

未经核验的示例图片不得被描述为真实学生作品、获奖案例、学校合作或飞行成功证据。资源更新不自动授权修改首页文字、公开发布或部署。

目录约定：

```text
resource/
  videos/              页面视频
  picture/
    student_works/     经授权的作品图片
    flight_png/        产品图片
    learning_kids/     学习场景图片
    UI/                界面截图
    awards/            经核验的奖项资料
```
