# 零件分类说明

> 状态：当前资产分类说明
>
> 更新时间：2026-08-15
>
> 适用范围：`apps/web/public/models/` 中的 GLB 展示资产
>
> 替代关系：补充共享零件 registry 的展示路径；不把 GLB 定义为二维制造源

⚠️ 重要：本目录下的零件分类**以子文件夹名为准**，与 GLB 文件名无关。

## 分类
- mainboards/  主板件（核心组件）
- landings/    起落架（从主板伸出的支架，承担落地 + 装电机/保护板的功能）
- guards/      保护板（吸附在起落架上的防护件）
- joints/      连接件（衔接装饰件，可选）

## 关于 GLB 文件名

历史原因，部分 GLB 文件名可能与所在文件夹名不一致
（例如 landings/arm_01.glb，文件名前缀是 arm 但分类是 landing）。

这是因为 GLB 在 Blender 导出时使用了旧的命名约定，
而文件夹分类反映的是**最新的业务定义**。

代码里通过**文件夹路径**判断分类，绝不通过文件名前缀。

未来计划：批量重命名 GLB 与文件夹一致（暂未排期）。
