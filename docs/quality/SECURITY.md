## 安全不变量

1. 身份、角色、资源归属、公开状态、审核、评分和发布资格由服务端决定；客户端字段和隐藏按钮不可信。
2. API 边界使用共享契约做运行时校验。用户文本、文件名、URL、SVG、DXF、图片和几何数据一律是不可信输入。
3. CAD 备用导出只接受受限 `partId`、限制零件总数，并在读取前确认真实文件仍位于 API 配置的批准目录内；目录穿越和越界符号链接必须拒绝。
4. CAD 备用导出按 `ownerId + designId/localId` 读取服务端作品；作者来自服务端用户，客户端作者、统计和检查结果不可信，也不得写入导出。
5. 写接口覆盖未登录、越权、非法输入、重复请求和并发；幂等键的生成方、作用域、期限和冲突语义必须写入契约。
6. 密钥只从环境或密钥服务注入；日志不得记录凭据、完整请求体或未成年人个人信息。
7. 认证、评论、点赞、上传、发布、搜索和复杂几何计算必须有速率、类型、尺寸和资源消耗限制。
8. 社区默认不公开真实姓名、精确位置、私信或未经审核的外链。年龄门槛、家长同意和学校数据先做合规评审。
9. 数据迁移、删除、扩大公开范围和权限模型变化必须有备份、回滚与人工批准。
10. 大模型不得进入权限、审核、评分、结构合规、制造或飞行等确定性决策路径。

## 变更验证

| 变更面 | 必须验证 |
|---|---|
| 鉴权、角色、管理入口 | 登录、登出、撤销、过期、跨用户访问、角色降级、直接调用 API |
| 写接口与状态机 | 非法字段、伪造 owner、非法状态跳转、重放、同键不同载荷、并发 |
| 上传、导出和外链 | 类型与大小、路径穿越、恶意 SVG/URL、存储归属、替换/删除失败与清理 |
| 社区、赛事和学校数据 | 普通用户越权、审核边界、公开范围、未成年人信息和数据最小化 |
| 数据迁移与删除 | 隔离数据、预演、数量对账、引用完整性、备份、回滚和审计记录 |
| 依赖与部署 | 冻结安装、生产与完整依赖审计、当前文件密钥扫描、历史凭据处置、真实凭证 smoke |
