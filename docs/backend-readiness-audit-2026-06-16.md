# 后端上线就绪体检报告（2026-06-16）

> **范围**：只查 `apps/api`，不碰前端。【只看不改代码】。
> **方法**：逐个过 models / routes / middleware / server.js / .env；连真实数据库实测关键接口（注册/登录/越权/存取/索引）；对照三份基准——RFC-011 架构、功能导图三端蓝图、上次 audit（2026-04-20）。
> **判定**：✅ 真能用（链路完整+鉴权+校验+错误处理）｜🟡 半成品（有模型没接口/没校验/TODO/没接通）｜❌ 没做。

---

## 0. 一句话总评

**后端的"地基"和"学生个人创作"这两块已经实打实能用，而且比 4 月那次体检进步巨大；但"社交/赛事/老师端/家长端"几乎是零，且有几处"看起来做好了、其实后端是空的"的坑。能不能上线，取决于上线版本只做"学生个人创作 + 个人作品库"，还是要带社区/班级。**

对比上次（2026-04-20）：后端当时 **2/5**（只有 5 个接口、1 张表 User、无安全中间件、admin 无鉴权、凭证泄露）。现在：**多张表 + 完整鉴权 + 安全中间件 + 数据持久化 + 上线健壮性**，安全三大债已基本清掉。**后端从"骨架"长成了"半个身子"。**

## 1. 按模块分类结论（大白话）

### 模块一 · 账号与权限
**【✅ 已做好、能用】**
- 注册、登录、JWT（7 天）、密码 bcrypt 加密、查当前用户、改个人资料——全通，实测正常。
- 防刷：注册/登录限流（15 分钟 20 次）。
- 管理后台"三道门"：访问密钥 + 登录 + admin 角色，缺一不可。
- **越权防护实测全过**：所有该登录的接口，不带令牌访问一律 401，没有越权漏洞。

**【🟡 做了一半】**
- 角色有 4 种（student/teacher/parent/admin），但**只有 admin 真的被用上**；teacher/parent 是"空头衔"，没有任何专属功能或权限。
- **改密码接口后端没有**（前端在调 `/auth/change-password`，后端不存在 → 点了会失败）。
- 没有 refresh token，令牌 7 天过期就得重新登录。

**能上线吗**：学生和管理员够用，可以上线；老师/家长角色目前是摆设。

---

### 模块二 · 创作三件（设计 / 编程 / 试飞）
**【✅ 已做好、能用】**
- **设计（DroneDesign）**：增删改查 + 幂等保存（同一设计存多次不会重复）+ 完整快照存储 + 缩略图，后端持久化**完备**，实测通过。
- **编程（Program）**：增删改查后端**完备**，实测：存进去的积木 XML 能原样取回。

**【🟡 做了一半 / 前端没接】**
- **编程保存：后端是好的，但前端"保存"是假的**（`CodingPage` 里是 TODO，只弹"已保存"提示、根本没存）——这就是你上一轮报的"积木消失" bug。后端 ready，等前端接。
- **设计：后端是好的，但前端"登录回填"没做**——换个浏览器登录拉不回设计（RFC-013 正在处理）。

**【❌ 没做】**
- **试飞（RunResult）后端完全没有**——没有模型、没有接口。试飞只活在前端内存里，**不存档、不能回放历史、不能当评分依据**。

**能上线吗**：设计/编程的后端能用；试飞只能"当场玩"，存不下来。

---

### 模块三 · 项目保存（M5 主线，导图标"正在做"）
**【✅ 已做好、能用】**
- Project 增删改查 + 把 设计/程序 绑进一个项目（designId/programId）+ 可见性字段 + **封面图上传**（实测：截图传上来、存储、回显都通）。

**【🟡 做了一半】**
- 有 `visibility`（private/public）字段，但**没有"查别人公开作品"的接口**（列表只查自己）——所以"分享/逛别人作品"目前看不了。

**【❌ 没做】**
- RFC-011 里 M5 要的**分享链接（shareId）、3 种分享粒度、版本/分支/回滚、协作者**——都没做。

**能上线吗**：自己把作品存起来、管理可以；但"作品分享出去"这个 M5 最大卖点还没通。

---

### 模块四 · 课程
**【❌ 基本没做】**
- 后端**没有课程模型、没有课程接口**，15/12 个课时内容全部写死在前端。
- 唯一沾边：能记录"用户完成了哪些课时 id"（`/me/lessons/complete`），但课程本身后端不管。

**能上线吗**：课程"展示"靠前端写死能跑；但课程内容要改就得重新发版，没有后台。

---

### 模块五 · 零件
**【🟡 做了一半（其实是"错了一半"）】**
- Part 模型存在，但字段是**旧的"采购清单"视角**（type=motor/prop/电机/螺旋桨、价格），和 RFC-011 要的"零件库"视角（HUB/ARM/保护罩、3D 模型、卡扣点、官方/UGC、审核状态）**对不上**。
- 没有任何零件接口（数据库里 parts 集合根本不存在 = 从没用过），零件数据全在前端写死。

**能上线吗**：零件"展示"靠前端写死能跑；后端零件库 = 没有。

---

### 模块六 · 社区（点赞/评论/收藏/fork/关注/排行）
**【❌ 没做】**
- 只有一个 `CommunityPost` 空模型（有 likes 字段但没接口），**发布/浏览/点赞/评论/收藏/合集/fork/关注/排行榜全没做**；评论、收藏、关注、排行甚至连模型都没有。

**能上线吗**：社区 = 0。

---

### 模块七 · 赛事（报名/赛道/评分/排名）
**【❌ 没做】**
- `Competition / Submission / Score` 三个空模型，**零接口零逻辑**；RFC-011 要的"赛道场景（Scene）"连模型都没有。数据库里这几个集合都不存在。

**能上线吗**：赛事 = 0。

---

### 模块八 · 老师端（班级/作业/成绩）
**【❌ 没做】**
- **零后端支撑**：没有班级、作业、学生管理、查成绩的任何模型或接口。
- ⚠️ 注意：公司商业主线是"先进公立学校（toB/toS）"。**老师端是 toB 的核心，目前完全空白**，这是最该提醒决策层的战略缺口。

**能上线吗**：toC 个人版可以不要它；toB 进校版没它不行。

---

### 模块九 · 家长端（看孩子作品/成长/鼓励）
**【❌ 没做】**
- 零后端：没有家长-孩子关联、没有"看孩子作品/成长"的接口。依赖学生端社区/分享先做出来。

**能上线吗**：家长端 = 0。

---

### 模块十 · 上线健壮性
**【✅ 已做好】**
- 数据库连接：有超时设置 + 断线重连监听 + 启动失败明确报错（不再静默卡死）。
- 优雅关闭（容器重启/部署时不留半截连接）。
- 健康检查 `/api/health` + `/healthz`，会反映数据库连没连上（挂了返回 503）。
- 安全中间件齐：helmet、限流、CORS 白名单（实测预检正常）。
- 反向代理信任（`trust proxy`），上线在 Nginx/SLB 后限流才准。
- 错误统一返回 JSON，未知路由返回 JSON 404（不漏默认 HTML）。
- **密钥全在 `.env`，代码无硬编码，git 历史从未提交过 `.env`**（红线安全）。
- 核心表有 `ownerId` 索引，设计表有 `(ownerId,localId)` 复合唯一索引（防重复）。

**【🟡 上线前要补】**
- **列表接口没有分页**——现在数据少（14 用户/1 设计）不会出事，但**学校批量上量后，一次全量返回会拖垮接口**。这条上线前必补。
- 日志只有 `console`，没有结构化日志/持久化，线上排障会吃力。
- 没有 CI/CD、`apps/api` 没有自动化测试（重构没有回归保障）。

**【❌ 没做】**
- 上线监控告警（CPU/内存/慢查询/错误率）。

## 2. 预期差：导图/RFC 里"以为做好了"、后端其实没做完

这几处最容易让产品/决策误判，单独拎出来：

| 功能 | 蓝图/RFC 标的状态 | 后端真实情况 | 差距 |
|---|---|---|---|
| **试飞** | 导图标"已能用"✅ | 后端**无 RunResult 模型/接口** | 试飞数据零持久化，存不下、回放不了、不能评分 |
| **编程** | 导图标"已能用"✅ | 后端 ready，**前端保存是假 TODO** | "积木消失" bug（你已发现） |
| **设计** | 导图标"已能用"✅ | 后端 ready，**前端登录回填没做** | 换设备读不回设计 |
| **作品保存** | 导图标"正在做"🟠 | 基础 CRUD 有，分享/版本/协作没做 | M5 只做了 1/3 |
| **课程** | 前端有 15 课时 | 后端**零** | 课程内容改不了、无后台 |
| **零件** | RFC 要零件库 | Part 字段是旧采购视角、无接口 | 字段对不上 + 没接口 |
| **一批前端在调、后端不存在的接口** | 前端 `api.ts` 里有 | 后端**没有** | `/designs` 增删改查、`/designs/public`、`/upload`、`/auth/change-password`、`/courses` —— 前端调了会失败或默默走 localStorage |

> 最后一行特别要紧：前端代码里有 6 处接口调用指向**后端根本不存在的地址**，上线后这些功能会静默失败。

## 4. 上线建议（按版本范围）

- **若首发 = "学生个人创作版"**（设计+编程+个人作品库）：补完 Top 1–6 即可上线，体验闭环成立。
- **若首发要带"作品分享/社区"**：还需 M7 社区后端，工作量大，建议分期。
- **若首发要进学校（toB）**：必须先做 M-F 老师端（班级/作业/成绩），这是目前最大空白，且是商业主线，强烈建议优先立项。
