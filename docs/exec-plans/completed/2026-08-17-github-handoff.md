## 目标与边界

本轮目标是在不修改原始脏工作树的前提下，为当前干净工程编写可独立接手的详细说明，重新执行完整验证，并把当前受版本控制的完整文件树上传到 GitHub。

本轮没有修改首页或其他页面文字，没有新增产品功能，没有关闭硬件、制造、实飞、外部服务或发布阻塞，没有合并或覆盖 `main`，也没有改变 GitHub 仓库可见性。

## 风险判断

远端仓库当前已经公开。直接推送本机开发分支会新增公开 37 个任何远端分支都不可达的祖先提交，而 `CURRENT_STATUS.md` 仍登记历史凭据轮换与清理未完成。公开仓库还包含儿童相关图片，其肖像与使用授权没有核验。

因此本轮不直接上传开发分支历史，只把最终已验证 tree 作为无父根快照建立 `codex/clean-handoff-2026-08-17`。它包含当前全部受版本控制文件，不包含这 37 个本机祖先。远端验证发现交付配置问题时，只在根快照上追加小型快进修复，仍不接入开发祖先。代价是快照分支不能作为与 `main` 共享历史的普通合并分支。
