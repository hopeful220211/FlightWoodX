**v0.2 评审修订**（采纳 Codex 计划关意见）：① `ProjectSummary`→`ShareProjectSnapshot`（不抢 A 的项目领域模型）；② `ShareDescriptor` 改判别联合；③ 补公开分享安全/隐私 DoD；④ `ReplayBundle` 加版本/溯源字段；⑤ `fork`→`createForkDraft`（命名诚实）；⑥ `editable-editor` 明确为 `forkable-preview` 兼容语义；⑦ readonly-project 首版用缩略图/文本不内嵌 GLB（避 WebGL context 溢出，§2.4）。

---

## 1. 目标与非目标

### 1.1 目标（可验证）
- **公开分享链接** `/s/:shareId`：免登录可达，独立 `ShareLayout`（不挂 `AppLayout` / 主导航）。
- **三种嵌入粒度**（§6.4）：`readonly-project` / `editable-editor` / `replay-only`，均可经 `<iframe>` 嵌入小红书 / 学校站。
- **可观战回放查看器**：消费遥测帧序列，可播放 / 暂停 / 重置 / 进度拖拽 / 调速，可独立嵌入。
- **契约入 `packages/shared/src/share.ts`**：`ShareDescriptor`、`EmbedGranularity`、`ReplayBundle`、`ForkProvenance`、`createForkDraft()`、`ShareProjectSnapshot`。
- 三态（加载/空/错误）齐全、响应式、**无 console 报错**、公开分享安全边界（§6.2）。

### 1.2 非目标（明确不做）
- 不做后端分享持久化/短链服务（M5.5 用 fixture + 前端契约；后端归后续 M）。
- 不做真·内嵌可交互编辑器（触碰 `features/project`，红线禁止）——`editable-editor` 收敛见 §5.3。
- 不改任何视觉 token/主题；不做 fork 服务端落库（只定义契约 + 前端入口 + provenance）。
- 首版项目卡不内嵌 3D GLB（避 WebGL context 溢出），用缩略图/文本。

## 2. 现状勘察结论（Codex 已核对属实）

| 事实 | 影响 |
|---|---|
| `RunResult = { success; score?; events[] }`，**不含遥测序列**，定义在 IR 文件 `commandProtocol.ts`（红线禁改） | 回放不能"重放 RunResult"，也不宜"重跑 IR"（暴露 program、受 adapter/scene 版本漂移）。→ 在 `share.ts` 新建 **`ReplayBundle`**（遥测帧序列 + RunResult），忠于 §6.3"可序列化遥测=回放数据源"，不碰 IR。 |
| `Telemetry = { posCm; headingDeg; frontDistanceCm }`，经 `onTelemetry` 逐 tick(默认 50ms) 流出 | 帧序列天然可采集；`ReplayBundle.frames` 即遥测快照序列。 |
| `FlightScene` 是纯 props 组件：`telemetry/trail/obstacles/ledColor` | 回放查看器**只 import 复用，不改源码**；逐帧喂 props 重放。注意位置在 `useFrame` 写 ref，seek 后下一帧反映——需实测拖拽 seek 画面正确。 |
| 项目无 `features/` 目录；红线列出 `features/share`/`features/project`/`features/growth` | 团队正引入 `features/` 模块约定 → 新建 `apps/web/src/features/share/`。 |
| 路由集中 `App.tsx`，主应用在 `AppLayout`（含 Navbar）下 | `/s/:shareId` 挂 `<Routes>` 顶层、独立 layout、不进 `ProtectedRoute`（与 `/auth` 同级）。 |
| `shared/project.ts` 不存在（归 A） | 用 `ShareProjectSnapshot`（公开安全字段，**非** A 的 Project）+ fixture；不抢 C1 边界。 |

## 3. 契约设计（`packages/shared/src/share.ts` 新增；`index.ts` +1 导出）

> 只 `import type` IR 类型，**绝不修改** `commandProtocol.ts`。

```ts
import type { Telemetry, RunResult } from './commandProtocol'

/** 三种嵌入粒度（对标 MakeCode；editable-editor 在 M5.5 为 forkable-preview 兼容语义，见 RFC §5.3） */
export type EmbedGranularity = 'readonly-project' | 'editable-editor' | 'replay-only'
export const EMBED_GRANULARITIES: readonly EmbedGranularity[] =
  ['readonly-project', 'editable-editor', 'replay-only'] as const

export type ShareKind = 'project' | 'run'

/** 回放单帧 = 可序列化遥测快照 + 高亮信息 */
export interface ReplayFrame {
  tMs: number                 // 相对起飞毫秒
  telemetry: Telemetry        // 复用 IR 类型
  cmdIndex?: number           // 当前指令下标（高亮）
  ledColor?: [number, number, number]
}

/** 回放场景障碍（结构等价 web 端 SimObstacle，但 shared 不依赖 web 层） */
export interface ReplayObstacle { posCm: [number, number, number]; radiusCm: number }

/** 一次"可观战的 Run" = 帧序列 + 结果 + 场景 + 版本/溯源 + 元信息 */
export interface ReplayBundle {
  schemaVersion: string       // 回放格式版本（本契约）
  protocolVersion?: string    // 产出时的 IR COMMAND_PROTOCOL_VERSION
  adapterVersion?: string
  sceneId?: string
  sampleMs?: number           // 采样间隔（对应 SimAdapter tickMs）
  frames: ReplayFrame[]
  result: RunResult           // 复用 IR 类型
  obstacles?: ReplayObstacle[]
  meta: { title?: string; authorDisplayName?: string; durationMs: number; recordedAt?: string }
}

/** 公开项目快照：仅含分享页所需的**安全公开字段**（不含账号 id / 儿童真实身份 / 私有素材）。
 *  ⚠️ 这是 C3 的对外快照，**不是** A 的项目领域模型；A 的 shared/project.ts 就位后，
 *  由 SharePage 在边界处把 Project 映射成本快照，share.ts 不 import A 的核心类型。 */
export interface ShareProjectSnapshot {
  shareId: string             // 公开标识，非内部 projectId
  name: string
  authorDisplayName: string   // 仅展示名
  thumbnailUrl?: string       // 受信白名单
  summary?: string
  createdAt: string
}

/** fork 溯源（§6.4：provenance 必记） */
export interface ForkProvenance { from: string; forkedAt: string }

/** fork 草稿：M5.5 只产出草稿 + provenance；**真实创建项目归 C1/API**。 */
export interface ForkDraft {
  name: string
  fromShareId: string
  provenance: ForkProvenance
}
export function createForkDraft(source: ShareProjectSnapshot, now: string): ForkDraft

/** 分享描述符（判别联合，杜绝非法状态） */
interface ShareDescriptorBase {
  shareId: string
  granularity: EmbedGranularity
  provenance?: ForkProvenance
  createdAt: string
}
export type ShareDescriptor =
  | (ShareDescriptorBase & { kind: 'project'; project: ShareProjectSnapshot; replay?: ReplayBundle })
  | (ShareDescriptorBase & { kind: 'run'; replay: ReplayBundle; project?: ShareProjectSnapshot })
```

**对 `@fwx/shared` 的影响**：纯新增类型 + 1 个纯函数 + `index.ts` 追加 `export * from './share'`。无运行时副作用，不触碰 IR/models/rbac/admin。

## 5. 关键设计

### 5.1 回放查看器（复用 FlightScene，不改它）
- `useReplayPlayer(bundle)`：维护 `frameIndex/playing/speed`；按 `tMs` 推进；暴露 `play/pause/reset/seek(idx)/setSpeed`。
- 渲染：`telemetry=frames[i].telemetry`；`trail=frames.slice(0,i+1).map(f=>f.telemetry.posCm)`；`ledColor=` 最近非空；`obstacles` 映射给 `FlightScene`。
- 控件：播放/暂停、重置、进度条（拖拽 seek）、速度档（0.5×/1×/2×）、轻量事件日志 + 结果徽章（success/score）。
- **seek 实测**：拖拽后立即校验画面无人机位置正确（Codex 提醒的 `useFrame` ref 时序）。

### 5.2 路由与 ShareLayout
```tsx
<Route path="/s/:shareId" element={<ShareLayout />}>
  <Route index element={<SharePage />} />
</Route>
```
- `ShareLayout`：**无 Navbar/主导航**；普通模式轻品牌条（logo + "查看完整作品"）；`?embed=1` 完全无 chrome 铺满，适配 iframe。
- 嵌入：`/s/:shareId?embed=1&g=<granularity>`，`g` **必须过白名单**（`EMBED_GRANULARITIES`），非法值降级默认。

### 5.3 三种嵌入粒度语义（`editable-editor` 收敛 — **本 RFC 待人类确认点**）
| 粒度 | 渲染 | 依赖 |
|---|---|---|
| `replay-only` | `ReplayViewer`（纯回放，可观战，可嵌入） | 仅 `ReplayBundle`（**零依赖 A**） |
| `readonly-project` | 只读项目卡：名称/作者展示名/缩略图/概要 + "Fork 改编"（首版**不内嵌 GLB**） | `ShareProjectSnapshot`（fixture） |
| `editable-editor` | **forkable-preview**：只读预览 + 醒目"Fork 到我的工作台编辑" CTA（`createForkDraft()`→provenance→引导登录/跳 `/projects`）。**非** iframe 内编辑器 | `ShareProjectSnapshot`（fixture） |

**收敛理由**：MakeCode 原义是内嵌可交互编辑器；红线禁碰 `features/project`，真内嵌既越界又超 M5.5 杠杆点。收敛为"可改编入口"保证粒度**可用、契约完整、守红线**；真内嵌待 A 提供可嵌入只读编辑器视图后在接缝升级（后续 M）。**DoD 据此按 forkable-preview 验收，不按 MakeCode 原义。**

### 5.4 解耦与并行（不被 A 阻塞）
- **第一梯队（零依赖 A）**：`share.ts` 契约 + `ReplayBundle` fixture + `ReplayViewer` + `ShareLayout` + 路由 + `replay-only` + 嵌入。
- **第二梯队（对 fixture）**：`readonly-project`/`editable-editor` 用 `ShareProjectSnapshot` fixture；A 的 `project.ts` 就位后，仅在 `SharePage`/`useShareDescriptor` 边界处把 Project 映射成快照（单点接缝，share.ts 不变）。

### 5.5 fixture 帧序列来源
首选**离线运行 `SimAdapter` 采样**（确定性运动学，数据真实）：用 `DEMO_PROGRAM` 跑一遍、收集 `onTelemetry` 帧固化成 JSON。若离线运行成本高，退化为手工采样一段合理轨迹（takeoff→forward→rotate→forward→land）。两者都只产数据、不改 SimAdapter/IR。

## 6. 量化验收 DoD

### 6.1 功能
- [ ] `/s/:shareId` 免登录可达（隐身窗口无 token 直接渲染成功）。
- [ ] 三粒度均可渲染：`readonly-project`/`editable-editor`/`replay-only`。
- [ ] 回放可**播放/暂停/重置/拖拽进度/调速**，无人机沿轨迹运动、轨迹线增长；拖拽 seek 后画面立即正确。
- [ ] `?embed=1` 无 chrome，可经 `<iframe>` 嵌入；`EmbedCodeCard` 复制片段可用。
- [ ] `createForkDraft()` 契约存在，`editable-editor`/`readonly-project` 有 fork 入口并产出 `provenance{from}`。
- [ ] 三态齐全（加载骨架/空/错误）；响应式（桌面+移动）；**无 console 报错**。

### 6.2 安全与隐私（公开分享，Codex 必改项）
- [ ] 只输出公开快照：**不暴露**账号 id / 儿童真实姓名 / 私有素材（仅 `authorDisplayName`）。
- [ ] `g` 参数过 `EMBED_GRANULARITIES` 白名单；未知值稳定降级，不渲染任意输入。
- [ ] iframe 嵌入码用 `URL`/编码安全生成，**禁止** `dangerouslySetInnerHTML` 拼接；外部 `thumbnailUrl` 受信白名单。
- [ ] 确认分享页不被 `X-Frame-Options: DENY/SAMEORIGIN` 阻断嵌入（前端层只做可控渲染，部署头策略记入开放问题）。

### 6.3 工程与降级
- [ ] `pnpm lint && pnpm typecheck` 全绿；改了 shared 跑 `pnpm --filter @fwx/shared test`。
- [ ] 非法 `g` / 未知 `shareId` / 空 `frames` 均有稳定降级（错误/空态，无白屏无报错）。
- [ ] 只动允许范围；未触碰 IR / `project.ts` / `features/project` / `features/growth` / 主导航。
- [ ] 附 6+ 截图；独立分支 `feat/m5.5-share` + 独立 PR + commit hash；勾选 RFC-011 §9 M5.5 项。

## 8. 停止点 🛑 与开放问题
- 🛑 **本 RFC（已过 Codex 评审）经人类确认后**再写代码。**待确认点：`editable-editor` 收敛为 forkable-preview 是否接受为 M5.5 DoD。**
- 开放问题（部分 Codex 已答）：
  1. 部署层响应头（`X-Frame-Options` / 未来 CSP `frame-ancestors`）允许嵌入来源——前端不决定，记给运维/迁移阶段。
  2. fixture 帧由离线 SimAdapter 采样 vs 手工采样——执行时择优（§5.5）。
  3. `shareId` 生成与不可枚举性——后端持久化阶段落实（M5.5 前端用 fixture id）。
