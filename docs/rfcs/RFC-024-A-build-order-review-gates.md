# RFC-024-A · 建造顺序与审查关（简化作战手册）

> 从属于 [RFC-024 总纲]。状态：执行中 · 2026-07-03 · 军师×Codex 两轮定稿
> 目的：把总纲 Phase 1–3 落成「最省力、不镀金」的建造顺序 + 每阶段一道轻量审查关。
> 一句话：**1.0 的命脉是「导出的切割图能不能真被激光机切出来」。切割图不可信 = 没有 1.0。先杀这条。**

---

## 一、建造顺序（严格按此，先打通脊柱再补肉）

1. **冻结最小制造契约**：零件制造源头 = `geometry2d`（单位 mm、厚度常量 2、外轮廓 + 内孔）。`.obj` 只当预览副产物，**永不作为导出来源**。
2. **官方件真导出**：给五步搭建里**实际用到的官方件**补 2D 轮廓源数据（DXF/轮廓），**绝不做 `.obj → DXF` 逆推**（逆推出来的线不可切）。
3. **打通导出 zip**：`DXF + SVG + BOM + assembly.md + manifest.json`。manifest 写死 `schemaVersion / units=mm / thickness=2 / part hash / count`。
4. **工坊保存落库**：服务器 = 唯一正式库，本地只做 draft/cache。**不做离线同步、冲突合并、双向 merge。**
5. **下沉 `@fwx/flight-check`**：把现有前端起飞检查规则原样搬进共享包，前后端同源。**先不扩物理模型。**
6. **提前补最薄审核接口**：`submit → pending → approve/reject` + 后台列表能点通过/拒绝。**不等 Phase 3**——验收脚本现在就断在这。
7. **Phase 2 用户画零件**：画 2D → 5 项检查 → 保存 → 插入搭建 → 导出。
8. **Phase 3 收尾**：零件广场 + fork + 发布徽章。发布时**服务端重跑 geometry + flight-check，客户端结果一律不可信**。

## 二、三个新技术块「够用就好」的边界（防过度工程）

**@fwx/geometry（DXF 生成）**：用 **maker.js**（薄适配一层，不把业务绑死），DXF 作权威制造文件、SVG 作预览/备用导入。
- 只支持：mm、闭合 polyline、外轮廓+孔、单层 `CUT`、2mm。
- **砍掉**：kerf 补偿、自动排版 nesting、材料库、多厚度、G-code、Bezier/spline 保真、OBJ 反推。
- DXF 写死 `$INSUNITS=4`（mm）；仓库放一个 **20mm 标定方块** 测试文件，用真实激光软件人工验一次比例。

**卡扣印章**：第一版**只做 2 个印章**——`slot`（内切槽）、`edgeNotch`（边缘缺口）。参数围绕 2mm 板材、长度从少数 preset 选。**砍掉**：约束求解、自动配对、智能吸附、特征树、自由布尔编辑。印章 = 生成确定性 cut loop 的小工具。

**可制造性 5 项检查**：全做成**纯函数**，前端即时提示 + 服务端保存/发布/导出前重跑。
1. 封闭：闭合、无自交、孔在外轮廓内。
2. 最小筋宽：保守 segment distance，`MIN_RIB_MM=3`（常量，不上 medial-axis）。
3. 幅面内：只支持一个配置幅面（不做多机型）。
4. 印章不越界：slot 完全在外轮廓内、edgeNotch 命中一条边、不与其他 cut loop 重叠。
5. 重量：`(外轮廓面积 - 孔面积) × 2mm × 木材密度常量`，**标"估算"、不参与"保证能飞"**。

## 三、每阶段审查关（轻量，抓要命的）

**四条通用红线（每个 Phase 都核）：**
- `[自动]` **契约**：跨端类型只来自 `@fwx/shared`/`@fwx/parts-schema`；`rg` 查 web/api 私自重定义 DTO。
- `[自动+人工]` **LLM 隔离**：geometry / flight-check / 导出 / 发布 / 审核判定路径，**禁止任何 LLM import**；PR diff 人工扫一眼。
- `[自动]` **确定性复核**：同一 fixture 前端与服务端跑出同样 geometry/check/flight 结果。
- `[人工]` **诚实文案**：禁用「100% 起飞 / 保证可造 / 保证安全飞行」。

**Phase 1 收尾：**
- `[自动]` zip 解包：至少 1 个 `.dxf` + 1 个 `.svg` + BOM + 装配说明 + manifest；part count 对得上。
- `[自动]` DXF smoke test：非空、单位 mm、闭合轮廓、bbox 与 fixture 误差 < 0.1mm。
- 🔴 `[人工·发布阻断]` 用 LightBurn/LibreCAD/Inkscape 任一**真实软件导入 DXF**，看比例/闭合/层/切割路径可用。
- `[自动]` 工坊保存后刷新浏览器仍能加载；本地 draft 不重复迁移。
- `[自动]` flight-check 前后端同 fixture 同分。
- `[人工]` submit 后默认 pending，未审核不进公共社区。

**Phase 2 收尾：**
- `[自动]` 5 项检查各有 golden fixture（合法/未闭合/筋太窄/越界/印章越界/重量）。
- `[自动]` 服务端拒绝「绕过前端检查」的非法零件。
- `[自动]` 用户零件插入搭建后，导出 zip 里真出现对应 DXF/SVG。
- `[人工]` 画 3 个零件走全链路（一合法/一太窄/一越界），确认 UI 阻止明确。
- 🔴 `[人工·发布阻断]` 抽一个用户零件导入真实激光软件。
- `[人工]` 印章 palette/schema **不出现电机/螺旋桨/电调/电池** 等电子件语义（宪法③）。

**Phase 3 收尾：**
- `[自动]` 审核状态机：pending 不公开、approved 才进广场、rejected 不可被 fork。
- `[自动]` 发布徽章只信服务端重跑结果，篡改客户端分数无效。
- `[自动]` 权限：仅 moderator 能 approve/reject；fork/评论/点赞有鉴权 + 限流。
- `[自动]` UGC 安全：文本长度/脏词/URL/文件名/SVG 展示方式/**zip 路径穿越**/超大 geometry 全部限制。
- `[人工]` 后台走通「看零件图 → 通过/拒绝 → 下架/恢复 → 看操作日志」。
- `[人工]` 未成年人安全最小线：无私信、无地理位置、无真人头像、无公开真实姓名；注册/发帖前中性年龄筛查；未满 13/14 的社区写入先关；**1.0 不做家长同意流**。

## 四、额外风险（Codex 补，需记账）

`.com/.cn` 跨境数据合规 · SVG/XSS · 恶意超大几何 DoS · zip 路径穿越 · fork 版权/来源归属 · 旧本地作品迁移 · 审核员误操作审计 · **实物安全免责声明**（宪法③/⑤在法务上的投影）。
